# 関所の記録

関所が残す記録の欄と置き場所を決める。何を残すか・どこに残すか・書けなければ通さないことは ADR-0006 が決め、欄の名前と形、SQLite の表の形、本文の上限の値をこの文書（と実装）に委ねている。

## 置き場所

- 正本は `-db` で渡す SQLite のファイルである。ファイルのあるディレクトリが無ければ関所は起動しない（volume の mount 忘れを、空のディレクトリを作って隠さない）。
- 同じ記録を、1 件ごとに 1 行の JSON で標準出力にも出す。これは写しで、書けなくても要求は止めない。関所自身のログは標準エラーに出し、標準出力には記録だけが出る。
- 記録の表は `records` の 1 つで、SQLite の `user_version` で形の版を持つ。いまの版は 1 である。
- 同じファイルに、「初めて見る」の覚えの表 `seen` を記録と別に持つ（[知らせ](notices.md)）。組の種類（`pair`）・中身（`key`）・初めて見た記録の時刻（`first_time`）と番号（`first_record`）の 4 つの列で、組の種類と中身で 1 行である。`records` の形の版とは別に、無ければ起動のときに作る。古い記録を消すときにも消さない。

## 書く時と、書けないとき

| 記録 | 書く時 | 書けないとき |
|---|---|---|
| 開く宛先の要求（`http`） | 上流へ渡す前に 1 度書き、答えを流し終えたら残りを書き足す | 要求を上流へ渡さず、503 を返す |
| passthrough（`passthrough`） | つなぐ前に 1 度書き、接続が終わったら量と時間を書き足す | つながずに接続を切る |
| 断った接続・要求（`connection`・`http`） | 断るときに 1 度 | 断ることは変わらない。標準エラーに出す |
| 名前解決（`dns`） | 答える前に 1 度 | 答えずに SERVFAIL を返す |
| 振り分けの読み直し（`config`） | 読み直したとき・読めなかったとき | 標準エラーに出す |
| 関所自身の要求（`gate`） | 送る前に 1 度書き、答えを受けたら残りを書き足す | 送らない。知らせなら待ちに残し、後で送り直す |

- 書き足す前に関所が止まった記録は、`finished` が偽のまま残る。途中で切れた要求や接続が、そうと分かる形で残る。
- 標準出力の写しは、書き終えた記録だけを出す（書き足す記録は、書き足したときに 1 度）。

## 欄

JSON の名前で書く。SQLite の列は同じ意味の snake_case である（`request` は `request_text`・`request_size`・`request_sha256`・`request_truncated`・`request_binary` の 5 つの列に分かれる）。当てはまらない欄は空にする。

| 欄 | 中身 |
|---|---|
| `id` | 記録の番号 |
| `time` | 記録を始めた時刻（UTC） |
| `source` | どの向け直し元の待ち受けに来たか（`-source` の `name`） |
| `kind` | `http`・`connection`・`passthrough`・`dns`・`config`・`gate`（関所が自分で上流へ送った要求。いまは Alertmanager への知らせだけ） |
| `treatment` | 振り分けの扱い（`open`・`passthrough`・`deny`） |
| `name` | 宛先の名前（SNI と Host、または問い合わせた名前） |
| `address` | 元の宛先（IP とポート） |
| `method`・`path`・`query` | 要求の method・path・query |
| `verdict` | `allow` か `deny` |
| `reason` | そう決めた理由 |
| `request` | 要求の本文（下の表） |
| `status` | 応答の状態 |
| `responseBytes` | 作業環境へ流した応答の本文の大きさ |
| `bytesUp`・`bytesDown` | passthrough で送った量・受けた量 |
| `durationNs` | 上流へ渡してから流し終えるまで、または接続の時間（ナノ秒） |
| `dnsType`・`dnsRcode`・`dnsAnswer` | 問い合わせの型、答えの rcode、答えた IP の並び |
| `error` | 失敗の理由（上流へ渡せなかった、応答が途中で切れた、など） |
| `finished` | 書き終えたか |

## 要求の本文

| 欄 | 中身 |
|---|---|
| `text` | 本文の頭から上限まで。文字でない本文のときは空 |
| `size` | 本文全体の大きさ |
| `sha256` | 本文全体の SHA-256 |
| `truncated` | 本文が上限より長かった |
| `binary` | 本文が文字でない（NUL を含むか、UTF-8 でない） |

- 書きの要求（GET・HEAD・OPTIONS・TRACE 以外）は、振り分けの `bodyLimitBytes` までの本文を残す。読みの要求は本文の文を残さず、本文があれば大きさとハッシュだけを残す（ADR-0006 の「読みは欄だけ」）。
- 上限は、上流へ渡す前に読む量でもある。上限までを先に読んで記録に書き、残りは上流へ流しながら大きさとハッシュを数え、終わったときに書き足す。上限の手前で終わる本文は、渡す前の記録に大きさとハッシュまで入る。
- 上限で文字の途中が切れたときは、切れた文字を除いて残す。
- 要求のヘッダは残さない（鍵とサロゲートの載る場所であるため）。応答の本文も残さない。
- 関所自身の要求は、送った本文（知らせの alert の JSON）を、同じ上限まで残す。`source` と `treatment` は空である。

## 古い記録を消す

関所は起動したときと、その後 1 日に 1 度、`retentionDays` より古い記録（`time` で比べる）を消す。消した件数は標準エラーに出す。
